# 骨骼对比视频

[交互页面](../index.html)展示 GT、GELINA 和 DualTrack 的正面／侧面有声骨骼视频，可按语言、来源和文本筛选。[完整页面](index.html)无需 JavaScript 即可浏览。

共 43 个样本、114 段视频：GT 和 DualTrack 各 43 段，GELINA 为英语 22 段、西班牙语 6 段。中文和日语展示 GT 与 DualTrack。

页面媒体位于 `../skeleton/`，来源哈希与渲染信息见 [manifest.json](../skeleton/manifest.json)。本目录原有网格视频作为历史素材保留，不再显示在页面中。
